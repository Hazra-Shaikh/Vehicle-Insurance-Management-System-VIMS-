# 🚗 Vehicle Insurance Management System (VIMS) — SQL Project

## 📌 Project Overview
The **Vehicle Insurance Management System (VIMS)** is a SQL-based data analysis project focused on analyzing vehicle insurance data to generate meaningful business insights. Using MySQL, the project explores customer information, vehicles, insurance policies, payments, agents, and claims to evaluate business performance and insurance operations.

## 🛠️ Tools
- **Database:** MySQL
- **Tool:** MySQL Workbench
- **Dataset:** Excel / CSV

## 🔍 Key Analysis
- Analyzed customer, vehicle, and insurance policy data.
- Evaluated premium collections, claim trends, and agent performance.
- Calculated monthly premium running totals and customer loss ratios.
- Identified missing data using SQL joins and filtering.

## 💻 SQL Concepts
`JOIN` · `GROUP BY` · `Subqueries` · `CTEs` · `CASE WHEN` · `Window Functions` · `Aggregate Functions`

## 📊 Project Details
- **7 relational tables**
- **501 records**
- **20 SQL business questions**

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open MySQL Workbench and create the database:

   ```sql
   CREATE DATABASE vims;
   USE vims;
   ```

3. Create the seven tables using the provided SQL script or table definitions.
4. Import the CSV files into their corresponding tables, respecting foreign-key dependencies.
5. Execute the SQL queries to reproduce the analysis.
